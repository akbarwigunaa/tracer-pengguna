1. Login Admin

1.1 Mengakses Halaman Login

Halaman admin dapat diakses melalui dua cara:

  • Klik tombol "Admin" di pojok kanan atas halaman kuesioner
  • Atau langsung akses URL: https://tracer-pengguna-production.up.railway.app/admin/login

1.2 Proses Login

1Masukkan Password
Ketikkan password admin pada field yang tersedia. Password diberikan oleh pengelola sistem.
2Klik "Masuk"
Jika password benar, Anda akan diarahkan ke Dashboard Admin. Jika salah, muncul pesan "Password salah".
Sesi Login: Sesi admin berlaku selama 24 jam. Setelah itu, Anda perlu login kembali. Klik tombol "Logout" di header untuk keluar secara manual.

3.3 Menghapus Data

1Klik ikon tempat sampah (merah) pada baris yang ingin dihapus
Ikon berada di kolom "Aksi" paling kanan.
2Konfirmasi penghapusan
Dialog konfirmasi akan muncul: "Hapus data dari [Nama]?". Klik OK untuk menghapus atau Batal untuk membatalkan.
Peringatan: Penghapusan bersifat permanen dan tidak dapat dibatalkan. Pastikan Anda menghapus data yang benar. Disarankan untuk melakukan export Excel terlebih dahulu sebagai backup.

4. Import Data dari Excel

Fitur import memungkinkan Anda menambahkan data secara massal dari file Excel, berguna untuk memasukkan data historis atau data yang dikumpulkan secara offline.

4.1 Download Template

1Klik ikon Download Template di header
File template-tracer-pengguna.xlsx akan terunduh. File ini berisi:
  • Sheet "Data Respons" — kolom-kolom yang harus diisi, lengkap dengan contoh baris pertama
  • Sheet "Panduan" — penjelasan setiap kolom dan pilihan yang valid
  • Dropdown validasi — beberapa kolom memiliki dropdown otomatis (fakultas, tingkatan, kepuasan, skala kompetensi)

4.3 Upload File

3Periksa hasil
Notifikasi akan muncul: "Berhasil import X data. Y baris dilewati." Tabel data akan diperbarui otomatis.

5. Export Data ke Excel

Fitur export mengunduh seluruh data respons ke file Excel (.xlsx) untuk keperluan pengolahan lebih lanjut atau arsip.

1Klik tombol "Export Excel" di header
File tracer-pengguna-YYYY-MM-DD.xlsx akan langsung terunduh.

File Excel yang dihasilkan berisi:

  • Seluruh data respons dengan header berwarna navy blue
  • 22 kolom: No, Tanggal, Email, Nama Pengguna, Jabatan, No WhatsApp, Perusahaan, Lulusan, Jabatan Lulusan, Fakultas, Prodi, Tingkatan, Bidang, Kepuasan, Harapan, 7 Kompetensi, Tahun
  • Border pada semua sel

6. Laporan Per Prodi & Universitas

6.1 Mengakses Halaman Laporan

Klik tombol "Laporan Prodi" di header Dashboard. Halaman laporan menampilkan data agregat dalam bentuk card yang dapat di-expand.

6.2 Filter Data

FilterPosisiFungsi
Filter TahunKanan atasMemfilter data berdasarkan tahun pengambilan. Mengubah URL dan me-reload data dari server.
Filter FakultasKanan atasMenampilkan/menyembunyikan card prodi berdasarkan fakultas. Bersifat client-side (tanpa reload).

6.3 Card Laporan Universitas

Card pertama (latar gelap) menampilkan laporan keseluruhan universitas:

  • Info ringkasan: jumlah fakultas, jumlah program studi, total responden
  • Tabel Kepuasan Umum: distribusi frekuensi dan persentase
  • Tabel Tingkatan Perusahaan: Lokal, Nasional, Multinasional
  • Tabel Bidang Perusahaan: distribusi bidang usaha
  • Tabel Kompetensi: rata-rata dan distribusi per skala (Sangat baik / Baik / Cukup / Kurang) dengan jumlah dan persentase
  • Daftar Perusahaan/Instansi: tabel nama pengguna, jabatan, perusahaan, jabatan lulusan
  • Ringkasan Per Prodi: tabel total dan rata-rata kompetensi per prodi
  • Tombol Download Word: mengunduh laporan universitas dalam format .docx

6.4 Card Laporan Per Prodi

Setiap program studi memiliki card terpisah yang berisi:

  • Semua tabel yang sama dengan card universitas (khusus data prodi tersebut)
  • Harapan Pengguna: daftar harapan/masukan dari setiap responden
  • Tombol Download Word: mengunduh laporan prodi dalam format .docx

Klik pada header card untuk meng-expand atau menciutkan isinya.

8. Pengelolaan Data Per Tahun

Sistem mendukung pengelompokan data berdasarkan tahun pengambilan. Fitur ini berguna untuk membandingkan data antar tahun dan menghasilkan laporan per periode.

8.1 Bagaimana Tahun Ditentukan

  • Pengisian kuesioner online: tahun otomatis diisi tahun berjalan
  • Import dari Excel: jika kolom "Tahun" diisi, nilai tersebut yang digunakan. Jika kosong, otomatis diisi tahun berjalan

8.2 Filter Tahun di Dashboard

Pilih tahun dari dropdown di atas tabel data. Pilih "Semua Tahun" untuk melihat seluruh data. Jumlah data yang ditampilkan akan berubah sesuai filter.

8.3 Filter Tahun di Laporan

Pilih tahun dari dropdown di halaman laporan. Filter ini bersifat server-side — halaman akan dimuat ulang dengan data yang sudah difilter. Semua card prodi dan card universitas akan menampilkan data khusus tahun yang dipilih.

9. Tips & Praktik Terbaik

1
Backup Rutin Lakukan Export Excel secara berkala untuk menyimpan backup data. Simpan file di tempat yang aman.
2
Export Sebelum Hapus Selalu export data terlebih dahulu sebelum menghapus data apa pun, karena penghapusan bersifat permanen.
3
Gunakan Template untuk Import Selalu gunakan template yang disediakan untuk import data. Jangan mengubah urutan kolom atau nama header.
4
Isi Kolom Tahun saat Import Untuk data historis, pastikan kolom Tahun diisi dengan tahun pengambilan data yang benar agar pengelompokan dan laporan akurat.
5
Laporan per Tahun Gunakan filter tahun di halaman laporan untuk menghasilkan laporan per periode. Download Word per tahun untuk arsip pelaporan.
6
Jaga Keamanan Password Jangan bagikan password admin ke pihak yang tidak berkepentingan. Logout setelah selesai menggunakan dashboard.
